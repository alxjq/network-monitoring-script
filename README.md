# 🖧 Network Monitoring Script

A simple **network monitoring program** written in **Bash**.  

This script helps you track active connections, network usage, and interface statistics in real-time.

---

## 🚀 Features

- ✅ Monitor active network interfaces
- ✅ Display current network traffic
- ✅ List active connections and open ports
- ✅ Simple and lightweight (Bash-based)
- ✅ Designed for Linux

---

## 🧰 Requirements

- Linux system
- Bash shell
- Root permissions (required for monitoring some interfaces)
- `netstat` / `ss` / `ifconfig` / `ip` (depending on your system)
